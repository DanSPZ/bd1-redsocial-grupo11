# Diseñado una base de datos para una red social estudiantil.
## S1. Tarea. Modelo conceptual de la red social estudiantil Pascualina.

Materia: Bases de Datos I SD1006 G100.

Grupo: 11.

Integrantes: Daniel Steven Pineda Zafra.

Docente: Profesora: Oralia Cortes Grajales.

En esta oportunidad se presentó la necesidad de poder crear una red social estudiantil en el IU Pascual bravo debido a la gran cantidad de estudiantes de la universidad
y lo complejo que es poder administrar toda esa información, por ende una red social donde cada uno pueda interactuar según sus intereses, programar eventos, crear grupos de estudio,
entre otros, es la mejor alternativa para poder formalizar una comunidad estudiantil bastante solida.

Medellin, Antioquia.
